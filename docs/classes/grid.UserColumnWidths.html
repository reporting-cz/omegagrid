    Class UserColumnWidths

    Column widths the user set by dragging the header divider or by autofit (double click on the divider). An adapter refresh builds a new model from the adapter definition, which brings the definition widths back; apply puts the remembered widths on the new columns instead, the same way the filter and sorting are carried over. Columns are matched by their data key, so a column set that changed between refreshes keeps the widths of the columns that stayed; a column without a data key is matched by its index.
