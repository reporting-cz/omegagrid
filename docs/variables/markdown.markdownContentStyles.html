    Standalone stylesheet for the HTML produced by markdownToHtml.

    The editor/view styles live in the shadow DOM of og-markdown-view and target the ProseMirror/NodeView DOM (.ProseMirror, .milkdown-table-block, .og-callout-header, [data-kind], …). None of that applies to the serialized output of markdownToHtml, which is plain semantic HTML (<h1>, <pre>, <table>, …) plus the callout blockquote form (<blockquote class="og-callout og-callout-note" data-callout="note">).

    These rules are scoped under .og-markdown-content so a consumer includes them once and wraps the rendered HTML in that class — no global leakage, one source of truth for helpdesk / AI-module message rendering:

    const el = document.createElement('div'); el.className = 'og-markdown-content'; el.innerHTML = await markdownToHtml(md);

    and once per app / component:

    // raw consumer

    static styles = [unsafeCSS(markdownContentStyles)]; // Lit consumer

    Colours use the same --og-* theme variables as the editor, so it follows the host theme (light/dark) automatically.
