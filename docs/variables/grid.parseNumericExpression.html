    parseNumericExpression: (input: string) => NumericFilterGroups

    Parse a numeric filter expression into a disjunction of conjunctions (OR groups, each an AND-combined list of clauses).

    Supported syntax:

    • operators >, >=, <, <=, =/==, !=/<> followed by a number (e.g. > 100, =42, !=5)
    • a bare number, treated as an exact match = n (e.g. 42)
    • a range a..b, expanded to >= a and <= b (e.g. 10..20)
    • and / or connectors (case-insensitive), e.g. <10 or >20, >10 and <20.

    Combining rules: an explicit or starts a new OR group, an explicit and keeps clauses in the same AND group. When no connector is given between two clauses the implicit connector is OR if both are exact (=) clauses — a value list such as 1 2 3 — and AND otherwise (comparisons narrow, e.g. >10 <20).

    Note: a lone bare number is parsed here as = n; callers that want the "contains" text-search behaviour for a single number must check isSingleNumber.

    Decimal separator may be . or ,. Tokens that cannot be parsed are ignored.
